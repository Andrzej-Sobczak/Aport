# Materiały źródłowe

W `files/` przechowuj oryginały, które dotyczą tylko tego projektu. Materiał
wspólny lub zasilający wiki zostaje w `raw/`; podaj jego ścieżkę zamiast kopii.
Każdy oryginał ma jedno miejsce. Nie zmieniaj oryginałów podczas analizy. W opracowaniu podaj ścieżkę
do źródła i konkretne miejsce informacji. Osobny rejestr źródeł jest opcjonalny.

# Materiały do przekazania

W tym katalogu zapisuj wyniki prac przygotowane do przekazania odbiorcy.
Przygotowanie dokumentu nie oznacza zatwierdzenia przez osobę odpowiedzialną.
Jeżeli został zatwierdzony, zapisz tę decyzję krótko w dokumencie lub karcie
projektu. Przy istotnej zmianie zachowaj wcześniej zatwierdzoną treść.

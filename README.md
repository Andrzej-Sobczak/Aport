# Aport dla Pupilii — baza wiedzy

Wiedza o sieci sklepów Pupilia i dokumenty projektu Aport, czyli środowiska
pracy pracowników sklepów. Stan z 2026-11-22. Repozytorium zawiera same treści:
materiały źródłowe, wiedzę o sieci i dokumenty projektu.

Zacznij od [karty projektu](projects/pupilia/KARTA.md): podaje cel, zakres,
decyzję o zatwierdzeniu i następny krok.

## Jak czytać

- Oznaczenia **Dziś**, **Plan**, **Kierunek**, **Postulat**, **Interpretacja**
  i **Propozycja** mówią, skąd pochodzi dana treść: ze stanu obecnego, z dokumentu
  planistycznego, z wypowiedzi decydenta bez decyzji, z oczekiwań użytkowników
  albo od autora opracowania.
- Odnośniki w podwójnych nawiasach, np. `[[wiki/domain/pupilia-slownik|słownik]]`,
  podają ścieżkę od katalogu głównego repozytorium. Działają w Obsidianie
  po otwarciu repozytorium jako skarbca; w przeglądarce GitHuba korzystaj z listy powyżej.
- Zatwierdzona jest treść z 2026-11-22. Przy zmianie zachowaj tę wersję.
